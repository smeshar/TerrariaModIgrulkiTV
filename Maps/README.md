# Готовая карта Междуземья (Lands Between Map)

В эту папку можно поместить готовый файл карты Terraria (`EldenRing_LandsBetween.wld`), созданный и отредактированный в программе **TEdit**.

### Как использовать TEdit для создания карты:
1. Скачайте **TEdit** (бесплатный редактор миров Terraria).
2. Создайте новый мир нужного размера (рекомендуется Large — 8400x2400 блоков для полного масштаба Elden Ring).
3. Нарисуйте рельеф:
   - **Замогилье (Limgrave)**: Зеленые холмы, серый замковый кирпич (`Gray Brick`), каменные стены, костры (Campfire).
   - **Озерная Лиурния (Liurnia of the Lakes)**: Затопленные низины, вода, мрамор (`Marble`), синие кристаллы, затопленная академия Райи Лукарии.
   - **Звездные Пустоши (Caelid)**: Багровые земли (`Crimson Grass`, `Flesh Block`), гниль, кости (`Bone Block`).
   - **Плато Альтус (Altus Plateau)**: Золотые равнины, солнечные плиты (`Sunplate`), золотой кирпич.
   - **Вершины Великанов (Mountaintops of the Giants)**: Снег, лед, заснеженные сосны.
   - **Подземные реки (Сиофра / Нокрон)**: Гранит, кристаллы, звездный фон.
4. Расставьте точки интереса (Церковь Эллех, Замок Грозовой Завесы, Академия, Лагеря).
5. Сохраните карту и скопируйте файл `.wld` в папку миров: `%USERPROFILE%\Documents\My Games\Terraria\tModLoader\Worlds`.
